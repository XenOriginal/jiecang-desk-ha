## 1. 部署

`configuration.yaml` 里必须有：

```yaml
homeassistant:
  packages: !include_dir_named packages
```

```bash
CFG=/Lager/data/homeassistant        # 宿主机路径，容器内是 /config
scp homeassistant/desk.yaml root@YOUR_HA_HOST:$CFG/packages/
scp homeassistant/www/desk-vertical-slider.js root@YOUR_HA_HOST:$CFG/www/
docker exec homeassistant python -m homeassistant --script check_config -c /config
docker restart homeassistant         # check_config 通过再重启
```

> 先找配置目录挂在哪：`docker inspect -f '{{range .Mounts}}{{.Source}} -> {{.Destination}}{{"\n"}}{{end}}' homeassistant`，
> `Destination` 为 `/config` 那条的 `Source` 就是 `$CFG`。

## 2. 唯一运动入口：`script.desk_goto`

**为什么必须只有一个入口**：HA 对"写入相同状态"会去重。`number.set_value` 写入与当前相同的值时
不产生状态变化，ESPHome 收不到指令 —— 表现为**连着说两次「坐下」，第二次毫无反应且没有任何报错**。

所以固件把 `number.target_height` 的 `set_action` 拿掉了（只当数值框），另给无状态
`button.desk_apply_target`。HA 统一走：

```yaml
- 写 number.desk_target_height   # 内部已把值夹到 851–1129
- delay 250ms                    # 给 ESPHome 时间接收数值
- 按 button.desk_apply_target    # 无状态，每次都发
```

夹取逻辑（**不能省**，否则传 1130/850 会被 number 实体校验直接拒绝，前端只弹一句
「超出有效范围」，桌子纹丝不动）：

```jinja
{% set lo = states('sensor.desk_soft_min') | float(850) + 1 %}
{% set hi = states('sensor.desk_soft_max') | float(1130) - 1 %}
{{ [[height | int(0), lo | int] | max, hi | int] | min }}
```

另一个入口 `script.desk_go_preset`：`which=1..4` → 按对应 button（1=坐底，4=站顶）。
所有运动都收敛到这两个脚本上，急停 / 超时保护 / 日志只有一条路径。

## 3. 实体 ID 对照（2026-11-10 实际上线值）

ESPHome 设备名 `Desk` 与实体名重复带了前缀，所以是 `sensor.desk_desk_*` 这种双前缀：

| 实体 ID | 来源 | 说明 |
|---|---|---|
| `sensor.desk_desk_height` | 固件 | 当前高度 mm |
| `number.desk_target_height` | 固件 | 纯数值框（写入不动作） |
| `button.desk_apply_target` | 固件 | 把数值发出去 |
| `button.desk_step_up` / `_down` | 固件 | 单步 10–12 mm |
| `button.desk_sit` / `desk_stand` | 固件 | 记忆 1（851）/ 记忆 4（1129） |
| `button.desk_go_preset_2` / `_3` | 固件 | 记忆 2 / 3 |
| `button.desk_emergency_stop` | 固件 | 急停 |
| `sensor.desk_soft_min` / `_max` | 固件 | 850 / 1130 |
| `sensor.desk_preset_1..4` | 固件 | 记忆位高度 |
| `sensor.desk_rx_frames` | 固件 | 诊断：空闲时必须不动 |
| `binary_sensor.desk_desk_moving` | 固件 | 900 ms 内高度变过 |
| `cover.desk` | **HA 模板** | 0–100%，给 HomeKit / 语音 / 前端 |
| `binary_sensor.desk_sitting` / `_standing` | HA 模板 | 按行程中点判定 |
| `sensor.desk_standing_today` | HA | 今日累计站立时长（history_stats） |

> 换板子或改设备名后 `entity_id` 可能重算。改名前**先备份**
> `.storage/core.entity_registry` 与 `.storage/core.device_registry`。

## 4. cover 模板（两个坑）

```yaml
- name: Desk
  unique_id: desk_cover_esphome
  icon: mdi:desk          # ← 关键
  optimistic: false
  position: >-            # 0% = 851（坐），100% = 1129（站）
    {% set lo = states('sensor.desk_soft_min') | float(850) + 1 %}
    {% set hi = states('sensor.desk_soft_max') | float(1130) - 1 %}
    {% set h  = states('sensor.desk_desk_height') | float(lo) %}
    {{ ((h - lo) / (hi - lo) * 100) | round(0) | int | clamp(0, 100) }}
```

1. **不要设 `device_class`。** 设成 `shutter`/`curtain` 后前端整套文案变成"窗帘"，
   按钮提示是"打开窗帘/关闭窗帘"，与桌子完全对不上。给 `icon: mdi:desk` 即可。
2. **端点各内缩 1 mm。** 见 §2。

## 5. 坐站判定与统计

阈值取行程中点，**不写死 990**（改软限位后自动跟着走）：

```jinja
{% set mid = (lo + hi) / 2 %}
sitting  = height <  mid
standing = height >= mid
```

`sensor.desk_standing_today` 是 `history_stats`，`state: "on"`，从 `today_at('00:00')` 累加。

## 6. 四条自动化

| id | 触发 | 动作 |
|---|---|---|
| `desk_sit_reminder` | `sitting` 持续 45 min 且 `person.you` 在家 | 持久通知「该站起来了」（想自动升就把注释的三行打开） |
| `desk_stand_reminder` | `standing` 持续 60 min | 持久通知「站太久了」 |
| `desk_away_reset` | `person.you` → `not_home` 持续 10 min | 回记忆位 1（防止桌子留在半空挡路） |
| `desk_runaway_stop` | `moving` 持续 90 s | 急停 + 通知（正常全程约 8 s，90 s 意味着卡住/堵转） |

久坐提醒的 `for` 从"变成 sitting"开始算，桌子一升起来就自动复位，**不需要额外计时器实体**。

## 7. 前端卡片：`custom:desk-vertical-slider`

自写单文件 LitElement 卡片（412 行），因为 HA 自带卡片都是横向文字方向，与"桌子上下动"反直觉。

### 布局

```
┌──────┬──────────────┐
│      │   1035 mm    │  ← 大号高度
│ 竖条  │              │
│ 60px │   [▲]        │
│      │   [■]        │
│      │   [▼]        │
└──────┴──────────────┘
  底=851  顶=1129
```

左条底部 = 最低（坐），顶部 = 最高（站），符合"把桌子抬上去"的直觉。

### 配置

```yaml
type: custom:desk-vertical-slider
entity: cover.desk              # 状态源，默认 cover.desk
track_height: 280               # 竖条像素高度，默认 280
```

可选键：`min_entity`（默认 `sensor.desk_soft_min`）、`max_entity`（`sensor.desk_soft_max`）、
`script`（`script.desk_goto`）、`stop_entity`（`button.desk_emergency_stop`）、
`hold_delay` / `repeat_every` / `repeat_max`（默认 700 / 2000 / 12）。

### 交互设计（都是踩过坑的）

| 行为 | 实现 | 原因 |
|---|---|---|
| 拖动滑条 | **只更新本地预览，松手才发一帧** `script.desk_goto` | 在 `pointermove` 里发命令会把桌子拖成过山车 |
| 单步按下 | 立即发一步 | — |
| 长按 | 700 ms 后才开始，之后每 2 s 补一步，最多 12 步 | 步子太重会把行程跑飞 |
| 长按 ≥3 步后松手 | **补一次急停**兜底 | 最后一步可能还在跑 |
| 合成 PointerEvent | `setPointerCapture` 必须包 `try/catch` | 否则 `InvalidPointerId` 抛错中断渲染 |
| 按钮布局 | `.pad{flex:1}` + `button{flex:1 1 0; min-height:36px}` | 否则三个按钮挤在底部，中间一大片空白 |
| 图标大小 | `ha-icon{--mdc-icon-size:26px}` | 默认偏小 |

### 注册资源

```yaml
# lovelace/resources/create
{ "res_type": "module", "url": "/local/desk-vertical-slider.js?v=1" }
```

**改完文件必须把 `?v=` 版本号 +1**，否则浏览器吃缓存，会以为没生效。

真实存储文件是 `.storage/lovelace.lovelace`（不是 `lovelace`，那个是 9 月的残留）。
整份读写用 `lovelace/config` / `lovelace/config/save`。

## 8. 设备归区与改名（无需重刷固件）

直接走注册表接口，**不动 yaml**：

```python
# 设备：改名 + 归区
{"type": "config/device_registry/update",
 "device_id": "...", "name_by_user": "书桌", "area_id": "shu_fang"}
# 实体：只改显示名，entity_id 保持不变
{"type": "config/entity_registry/update", "entity_id": "...", "name": "..."}
```

⚠️ `has_entity_name=True` 的实体改设备名可能触发 `entity_id` 重算 —— 改名之前必须先备份
`.storage/core.entity_registry` 和 `.storage/core.device_registry`。
